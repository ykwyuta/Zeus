# Code page tables

Mapping tables generated by `tools/icu-codepages.sh` from the ICU UCM
files at pinned unicode-org/icu-data commit
`bae5ca647fa41703393dbf00240ec1b807a9c353`.
The data is under Unicode License V3 (`LICENSE-ICU`). `SOURCES` lists the
exact input revision of each table; `tables.rs` is generated from that manifest.
CCSID 37 uses Zeus's existing table; 1140 changes its currency position to euro.

Supported CCSIDs (54):

37, 273, 277, 278, 280, 284, 285, 297, 420, 424, 500, 838, 870, 871, 875,
930, 933, 935, 937, 939, 1025, 1026, 1047, 1112, 1122, 1123, 1130, 1132,
1137, 1140–1149, 1153–1160, 1164, 1364, 1388, 1390, 1399, 5026, 5035.

Mixed SBCS/DBCS pages: 930, 933, 935, 937, 939, 1364, 1388, 1390, 1399,
5026, 5035. All other pages in the list are SBCS. `ibm-N.sbcs` holds each
single-byte part; the double-byte parts are named by `SOURCES`. 930/939
share `ibm-300.dbcs`, and 1390/1399 share `ibm-16684.dbcs`.

The runtime converts bytes using these tables without ICU or iconv dependencies.
The tables do not implement locale-specific Arabic shaping or bidi display.

A line is `K EBCDIC UNICODE`: ICU's precision K (0 round trip, 1 fallback to
EBCDIC only, 2 to the substitution character, 3 fallback to Unicode only),
the EBCDIC code in hexadecimal and the Unicode code point(s) (`+` between
the two code points of a combining sequence). `crates/zeus-cobol/src/codepage.rs`
reads them; CCSID 037 is Zeus's own table.
