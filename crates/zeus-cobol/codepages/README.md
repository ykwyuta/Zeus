# Code page tables

Mapping tables of the Japanese EBCDIC code pages Zeus converts (CCSIDs
930, 939, 1390, 1399), generated by `tools/icu-codepages.sh` from the ICU
mapping files (UCM) of the unicode-org/icu-data repository at a pinned
commit. They are data of the ICU project, under the Unicode License V3
(`LICENSE-ICU`).

| File | Content |
|---|---|
| `ibm-930.sbcs`, `ibm-939.sbcs`, `ibm-1390.sbcs`, `ibm-1399.sbcs` | single-byte part of each code page |
| `ibm-300.dbcs` | double-byte part of 930 and 939 (CCSID 300) |
| `ibm-16684.dbcs` | double-byte part of 1390 and 1399 (CCSID 16684) |

A line is `K EBCDIC UNICODE`: ICU's precision K (0 round trip, 1 fallback to
EBCDIC only, 2 to the substitution character, 3 fallback to Unicode only),
the EBCDIC code in hexadecimal and the Unicode code point(s) (`+` between
the two code points of a combining sequence). `crates/zeus-cobol/src/codepage.rs`
reads them; CCSID 037 is Zeus's own table.
