DETAILED USAGE - zeus-ccvs

Run CCVS85/ZCVS (COBOL), ZPVS (PL/I), and ZHVS (HLASM), with shared
reports and standalone native executables. Extraction, execution and reporting are
separate commands. No external documentation is needed for this help.

EXTRACT
  zeus-ccvs extract --newcob newcob.val --out work/suite [options]
  --config FILE   EXEC85 X-card configuration (default ccvs85/exec85.conf).
  --overlay FILE  Apply additional X-card values afterward; repeatable.
  --verify FILE   Compare extraction with a reference manifest.
  The population file is expanded into test sources and their associated
  input files under --out; the reference manifest checks the extracted set.

RUN
  zeus-ccvs run --suite work/suite --toolchain KIND --out results.json [options]
  --toolchain KIND  gnucobol, zeus, zeus-native, zpli, zpli-native,
                    zas, zas-obj or zas-goff.
  --cobc FILE       GnuCOBOL compiler path (gnucobol).
  --zcobc FILE      Zeus compiler path (otherwise next to this executable).
  --zpli FILE       PL/I driver path (otherwise next to this executable).
  --zas FILE        Assembler path (otherwise next to this executable).
  HLASM uses zpli run-hlasm from the assembler's directory for callbacks.
  A failed/empty run returns nonzero; compile diagnostics must match.
  --work DIR        Working directory (default work/run); toolchain-specific
                    build/run files are written beneath it.
  --modules LIST    Comma-separated suite modules, e.g. NC,SM,IC. Defaults to
                    all supported modules present in the extracted suite.
  --programs LIST   Comma-separated program names; default all programs.
  --jobs N          Parallel workers (default 4).
  --timeout N       Per-step timeout in seconds (default 120).
  --out FILE        Required JSON results file; existing file is replaced.
  Native runs need zeus-rt available next to the compiler. Failed tests return 1.

REPORT
  zeus-ccvs report --results results.json [--results zcvs.json] [--baseline baseline.json] [--programs]
  --results FILE   Suite result JSON file (repeatable to merge CCVS85 + ZCVS).
  --baseline FILE  Compare counts with another recorded run.
  --programs       Include the detailed per-program results in the report.

MANIFEST
  zeus-ccvs manifest --out manifest.txt EXEC85_OUTPUT...
  Build a reference extraction manifest from EXEC85 output files.

EXPORT-JCL
  zeus-ccvs export-jcl --suite zcvs --out work/zcvs-zos [--hlq USER.ZCVS] [--modules LIST]
  Export a suite into 80-column PDS members (COPY/, SRCLIB/) and z/OS
  IGYCRCTL/IBMZPLI/ASMA90 + IEWL JCL job streams (JCL/).

EXAMPLES
  zeus-ccvs extract --newcob newcob.val --out work/suite --overlay ccvs85/exec85-zeus.conf
  zeus-ccvs run --suite work/suite --toolchain zeus --out results.json
  zeus-ccvs run --suite zcvs --toolchain zeus --out zcvs.json
  zeus-ccvs export-jcl --suite zcvs --out work/zcvs-zos --hlq USER.ZCVS
  zeus-ccvs report --results results.json --results zcvs.json --programs

EXIT STATUS
  0 command completed successfully; 1 test failure or empty run;
  2 invalid usage or harness failure. Outcomes are recorded in JSON.
  Use --help/-h for any command; --version prints the harness version.
